# Brochure-site design standard (rendered HTML)

Law lives in the hub; the content pipeline lives in marketing.md. This is
the visual standard for the rendered brochure **site**: a single
scrolling product page of the kind you publish on GitHub Pages to explain
your product. (The earlier keynote-deck standard was retired by owner
review — RED 6 in the eval record; decks live in git history if ever
wanted again.) Visual fundamentals were adapted from
microsoft/amplifier-bundle-stories `context/presentation-styles.md` and
`context/responsive-design.md` (MIT, repo @ 3657bf1).

## Artifact and placement

- One file: `docs/index.html`. GitHub Pages serves it at the project
  site root with the "deploy from branch, `/docs` folder" setting; the
  markdown docs become browsable alongside it, which is fine — they are
  the citations' targets.
- First line is the sentinel:
  `<!-- do not edit; generated by the superpowers-docs documentation
  skill from docs/BROCHURE.md @ <sha> -->` — both generated-file markers
  intact, `<sha>` = BROCHURE.md's stamp SHA (the regeneration cursor).
- No index row for the rendered file; BROCHURE.md's row carries the
  claims and the sentinel keeps `scan` off the render.

## Self-containment

- Inline CSS; system font stack; **zero JavaScript** (a scroll page needs
  none — anchors and `:target` cover navigation).
- **No external requests of any kind.** Repo-relative assets (images
  under `docs/images/` or similar) are allowed — they travel with the
  repo and GitHub Pages serves them; never hotlink, never inline
  base64 blobs.
- Stay lean; reference renders land well under 30 KB of HTML.

## Page anatomy (sections mirror the cast; the story law orders them)

1. **Header**: product name, the one-sentence what-it-is (BROCHURE.md's
   opening line, verbatim), a GitHub link, and anchor links to the
   sections below.
2. **The problem** — its own section, unresolved. Name the status-quo
   cost the reader bears today, concretely, and stop. **Never resolve
   the problem in the section that states it** (the mixing of problem
   and promise in one breath is the documented failure this rule
   exists to kill).
3. **What you get** (user): the promise, benefit-first, in the resolved
   voice. Benefit cards or short paragraphs; each benefit cashes
   against a cited capability.
4. **Using it** (user): the first-success path with real commands and
   really-produced output, kept short; link to the getting-started doc
   for the rest.
5. **Running it** (owner band, warm accent `#FF9F0A`): what you deploy
   and operate, the trust mechanisms, limitations tagged by bearer.
   The register shift is signposted by the accent and the section
   kicker.
6. **Doors**: one clear next step per cast member (try it / deploy it),
   plus the one-line contributor pointer. No sentimental closer.
7. **Footer**: license, repository link, and the verification line
   ("claims verified @ <sha>; see docs/BROCHURE.md").

## Citations (the honesty move, carried)

Every content section ends with a muted citation line naming the doc
sections that back it. The label is **`Sources:`** — never internal law
vocabulary ("cashes", "enacting surface", "verified-the-verb"); the
reader of this page has not read this skill, and skill jargon in copy is
a voice defect. Format: `Sources: docs/X.md §Y · README §Z · as of
<sha>`. Keep it quiet: one size below the body floor
(`clamp(10px, 1.4vw, 12px)`), `rgba(255,255,255,0.5)` on black (≈5.3:1,
still AA), no uppercase, no border. A section without a citation line
does not ship; a citation line that shouts defeats its purpose.

## Typography, color, accessibility

- Fluid type via `clamp()` for every size; never fixed pixels. Hero ≈
  `clamp(32px, 6vw, 64px)`; body ≈ `clamp(16px, 2vw, 19px)`; citations ≈
  `clamp(11px, 1.5vw, 13px)`. Comfortable measure: content max-width
  ~880px for prose, wider (~1100px) for card grids.
- Dark mode default (background `#0b0b0d`–`#000`, text `#fff`); WCAG AA
  floors: body ≥ 7:1, secondary ≥ 4.5:1 (`rgba(255,255,255,0.65)` is
  the floor for content). Card surfaces `rgba(255,255,255,0.06)` with
  `0.12` borders.
- Accent (`--accent`, default `#0A84FF`) for structure and links; the
  owner band swaps to the warm accent. Never accent-colored body text.
- Grids: `repeat(auto-fit, minmax(min(<col>px, 100%), 1fr))` so cards
  reflow on small screens. Generous section padding
  (`clamp(48px, 10vw, 120px)` vertical).

## Restraint

The copy obeys the resolved voice (default: the publication writer —
voice.md preset 5, with its zero-em-dash and zero-contrastive-negation
rules) and `references/elements-of-style.md`, which is required reading
before drafting. Show the product, not the adjectives: real commands,
real output, concrete benefits. Headlines are plain declarative
sentences.
